# Demo footage

Screen recordings for the demo video (David's script), taken from the latest release on 15 November 2026.
The phone takes are the iPhone 17 Pro simulator; the clock is set to 07:30 so the app is in its morning mode.
The pulse in the session comes from a recording-only driver that feeds the app finger-clip frames (calm, then a
stress ramp, then calm again), so the app reacts exactly as it does with the real clips. The clinic patients are
the seeded demo roster, labelled "Simulated" in the app.
